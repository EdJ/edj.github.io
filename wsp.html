A control plane for work, and for the agents doing it.

wsp owns the durable halfprojects, tasks, decisions and worklists, as markdown in a git repository. Every command commits the files it wrote, and only those. The backend is surface-agnostic, so building a custom UI on top is possible.
The demo UI is through herdrThe current implementation is a fork of herdr, primarily to leverage the multiplexing infrastructure.

part one

The record

One markdown file per project, task and worklist, in git.

01

Work is a tree

Projects nest, tasks hang off them — and everything set above a task applies to it.

  • A project carries what its work inheritsTags, decisions, a handbook, and the checkouts the work lives in.
  • Six statuses, two of them stoppedblocked is owed an answer, parked is the wrong moment. Both take a sentence.
  • The tool keeps the tree honestA parent cannot finish over an open child.
part two

Who answers for it

The agents, the seats above them, and everything that passes between.

02

So are the agents

A claim binds an agent to a task. A seat binds an agent to a project. Seats nest the way projects do, and end at a person.

  • One verb puts an agent on a taskwsp spawn <id> --agent — workspace, claim, agent, sentence, in that order. wsp despawn reverses it.
  • A coordination point, not an approval gateNo verb consults a seat before acting. The one guard runs the other way: despawn refuses to end a governing pane.
  • A governor’s job is not an agent’sSequence, direct, review against the code, hold the record — and do not claim work.
03

Agents talk to agents

Three channels between an agent and the seat above it — and only one of them refuses to be left open.

  • A flag is state, not storeNo commit, nothing in the task file — and it arrives as a card in every panel without anybody pressing anything.
  • Clearing is not answering--clear acknowledges; a question ends only by being answered or abandoned.
  • Asks are a closed vocabulary--ask claim, and nothing else yet. The answer runs a command, so an agent never names its own argv.
04

Being told, and what it costs

Seven predicates, derived once a minute, delivered by cost: two free surfaces, and one that re-reads a governor’s whole context.

  • The free surfaces carry everythingA hook and a sidebar token cost nothing, so both run for every level, unfiltered.
  • So a wake can be rationedA governor is woken only for what it must act on — which is why flag spools.
  • Silence still cannot pass for successAn unforeseen reading wakes: one needless context read against a wrong silence is not a fair trade.
part three

Running it

A queue driven in order, and a second machine.

05

Worklists

An ordered queue of groups, with a barrier between them where a person writes the verdict.

  • A plan is referencesMembers keep their own ids and projects. A list orders work from anywhere and owns none of it.
  • Two caps, and the smaller winsxN caps the group; the machine caps the fleet.
  • A queue, not an autopilotnext names the command; a governor runs it. A barrier will not pass without a sentence.
06

Another machine

The far machine holds no store, no state and no wsp binary, so there is nothing over there to keep in sync. Placement is one flag.

  • The id is the routing keyw0:p3@mb2. Calls carrying no id fan out across every reachable machine.
  • Unreachable is not emptyOne dropped link must not hand back every task the executor is holding.
  • Placement is asked for, never inferredThere is no affinity. Auto-placement hides the thing you most want to see.
